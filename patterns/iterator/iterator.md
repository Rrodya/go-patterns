# Iterator

Поведенченский паттерн проектирования, который предоставляет механизм обхода коллекций объектов не раскрывая их внутренного предстовления. 

Для реализации требуется
- Интерфейс `Iterator` описывающий набор методов для доступа к коллекции
- Класс `ConcreteIterator`, реализающий интерфейс `Iterator`. Следит за позицией текущего элемента при переборе коллекции(`Aggregate`)
- Интерфейс `Aggregate` описыващий набор методов коллекции объектов
- Класс `ConcreteAggregate` реализющий интерфейс `Aggregate` и хранящий в себе элементы коллекции
