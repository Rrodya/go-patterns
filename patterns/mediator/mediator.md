# Mediator

Паттер медиатор предстовляет объект посредник, скрывающий способ взаимодействия множества других объекто-коллег. Медиато рделает систему слабо связанной, избавляя объекты от необходимости ссылаться драг на друга , что позволяет изменять взаимодействие между ними независимо.

Для реализации требуется 
- Интерфейс `Mediator` - посредник описывающий организацию процесса по обмену информацией между оъектами типа `Colleague`
- Класс `ConcreteMediator`, реализующий интефрейс `Mediator`
- Базовый абстрактный класс `Colleague` - коллега описывающий организацию процесса взаимодействия объектов-коллег с объектом типа `Mediator`
- Класс `ConcreteColleague`, реализющий интерфейс коллеги. Каждый объект-коллега знает только об объекта-медиаторе. Все объекты-коллеги обмениваются информацией только через посредника
