# Command

Поведенченский паттерн проектирования, который упаковывает действие/запрос в объект. (что сделать, с какими параметрами и над каким олпучателем) Отделяет объект инициализирующий операцию от объекта который знает как ее выполнять. receiver, invoker.
Единстенное что должен знать инициатор это как отправить команду.

Для реализации требуется:
- Базовый абстрактный класс command описывающий интерфейс команды.
- Класс ConcreteCommand реализующий комманду 
- Класс invoker, реализующий инициатора, провоцирующий ее выполнение
- Класс receiver, реализующий получателя и имеющий набор действий, который команда может запрашивать.

Invoker -> ConcreteCommand -> Receiver
